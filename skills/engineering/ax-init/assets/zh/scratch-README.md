# .scratch 工作项索引

**怎么在这里工作（工作项结构、ticket 骨架、生命周期）见 [AGENTS.md](AGENTS.md)。**

## 目录

```text
.scratch/
├── active/                 # 尚未结束的工作项（不跟踪）
├── archive/YYYY-MM/<work>/ # 已完成工作项的历史资料（进 Git）
└── local/                  # Git 忽略的私人草稿和临时输出
```
