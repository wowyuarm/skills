# <repo> 文档导航

本目录存放仓库的维护性工程文档。根 `AGENTS.md` 只保留每个任务都要知道的规则；本目录的 [AGENTS.md](AGENTS.md) 规定文档的写作与维护——改 `docs/` 下任何内容前先读它。

## 从任务出发

先读任务明确引用的材料，再按下表补足缺口；不必通读整个目录。当前行为以源码与测试为准，文档给出理解与验证入口。（示例行替换为仓库的真实文档；两行诚实的行胜过十行占位行。）

| 你要做什么 | 先读 | 然后定位 |
| --- | --- | --- |
| （示例）开始开发或运行某个检查 | `development.md` | 它指向的脚本或配置 |
| （示例）改跨模块行为 | `architecture.md` | 它链接的实现与测试 |
| （示例）理解某个术语或边界 | `domain-model.md` | — |

## 每类事实的落点

| 落点 | 负责什么 |
| --- | --- |
| 根 `AGENTS.md` | 每个任务都适用的约束与阅读纪律 |
| 本目录 `AGENTS.md` | `docs/` 的写作与维护纪律 |
| `architecture.md` 类页面 | 各部分如何协作、每类事实归谁 |
| `development.md` 类页面 | 如何构建、验证与发布 |
| `.scratch/README.md` | 工作历史——设计、研究与证据；不是当前行为的权威 |
